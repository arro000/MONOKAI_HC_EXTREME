# Monokai HC Extreme

![Monokai HC Extreme theme preview](images/preview.png)

## A clear, high-contrast experience

A GitHub-inspired high-contrast interface with Monokai syntax highlighting, available in **dark** and **light** variants.

## Preview

- [Dark theme preview](https://vscodethemes.com/e/Zibro.monokai-hc-extreme/monokai-hc-extreme-dark?language=javascript)
- [Light theme preview](https://vscodethemes.com/e/Zibro.monokai-hc-extreme/monokai-hc-extreme-light?language=javascript)

## Install

1. Go to [VS Marketplace](https://marketplace.visualstudio.com/items?itemName=Zibro.monokai-hc-extreme).
2. Click on the "Install" button.
3. Open **Preferences: Color Theme** and select:
    - `Monokai HC Extreme light`
    - `Monokai HC Extreme dark`

## Examples

Enhanced highlighting for **C#**, **TypeScript**, **React JSX/TSX**, **Vue**, **Angular**, **Go**, **Rust**, **Swift**, **Bash**, **Ruby**, **Dart/Flutter** and **Java**.

See the [examples and highlighting guide](https://github.com/arro000/MONOKAI_HC_EXTREME/blob/main/examples/README.md) for code samples, color palettes and language-extension recommendations.

## Override this theme

Customize individual colors using VS Code's [color theme guide](https://code.visualstudio.com/api/extension-guides/color-theme).
